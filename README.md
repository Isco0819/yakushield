# 🛡️ yakushield (訳シールド)

`yakushield`（訳シールド）は、Claude Code などの LLM 自律型エージェントの **「暴走による超高額請求」** と **「日本語によるトークン浪費」** を二重に防ぐために作られた、軽量なローカル LLM プロキシサーバー & 可視化ダッシュボード（グラスモルフィズムUI）です。

Claude Code の環境変数 `ANTHROPIC_BASE_URL` をこのプロキシに向けるだけで、通信をリアルタイムに中継しつつ、コストの可視化と、設定上限に達した瞬間の **「物理的な予算遮断（予算ブレーカー）」** を提供します。

---

## ✨ コア機能 (Happy-Path MVP)

1. **物理予算ブレーカー (Physical Budget Breaker)**
   * 1日の累積LLMコスト（USD）が設定された上限（例: $5.00）を超えた瞬間に、LLMへの中継を完全に遮断。
   * 自律型エージェントに明確なエラー（`HTTP 429` 且つ Anthropic 準拠エラー形式）を返却することで、エージェント自身の安全な停止を促し、想定外の高額請求を物理的に防ぎます。
2. **リアルタイムコスト & トークン計測**
   * 中継したリクエスト・レスポンスの `usage` から正確なトークン（Input / Output）数を抽出。
   * 主要モデル（Sonnet, Opus, Haiku 等）の単価マトリクスを内蔵し、USD 利用金額を瞬時に集計。
   * **ストリーミングレスポンス（SSE）のパススルー解析**にも完全対応。
3. **日本語トークン浪費の見える化 (Japanese Token Waste Visualizer)**
   * 日本語文字を自動検知し、英語に比べ約3倍に膨れ上がる「日本語のトークン浪費」の規模（トークン数 / 損失額）をダッシュボード上でグラフィカルに可視化。
4. **グラスモルフィズム・ダッシュボード (http://localhost:4040)**
   * 同一プロセスで美しくインタラクティブな Web UI を提供。
   * スライダーを動かすだけで、予算上限を即座に変更可能。
   * **モック送信デモ・シミュレーター**を内蔵し、本物のAPIキーがない状態でも予算ブレーカーが遮断する様子をその場でテスト・体感できます。

---

## 🛠️ 技術スタック

* **Runtime**: Node.js + TypeScript (ESM)
* **Server**: 標準 `http` & `https` モジュールによる極限の軽量化（npx 起動が高速で、余計な依存関係なし）
* **Dashboard**: Vanilla HTML + 少量 JS + グラスモルフィズム CSS
* **CLI/npx**: `package.json` の `bin` に登録され、`npx yakushield` として実行可能

## 🚀 クイックスタート (ローカル起動手順)

本物のAPIキー（`ANTHROPIC_API_KEY`）が未設定の状態でも、自動的に **スタブ/モックモード** で起動するため、一切の費用を発生させずにダッシュボードや予算ブレーカーの動作テストが可能です。

### 1. インストールとビルド

```bash
# 依存関係のインストール
npm install

# TypeScriptのコンパイルとアセットの配置
npm run build
```

### 2. サーバーの起動

```bash
# プロキシサーバーを起動
npm start
```

起動すると、ターミナルに美しい ASCII ロゴと共に以下が表示されます：

```text
  🛡️  yakushield (訳シールド) ローカルプロキシ起動完了
----------------------------------------------------
  🔗  Dashboard UI:   http://localhost:4040
  🔌  LLM Base URL:   http://localhost:4040
----------------------------------------------------
  🧪  APIキー未検出:  スタブ/モックモードで動作中 (APIキー不要でテスト可能)
```

ブラウザで `http://localhost:4040` にアクセスして、美麗なダッシュボードを開いてください。

## 🔌 Claude Code 等との連携方法

実際のLLMリクエストを計測・遮断するには、環境変数 `ANTHROPIC_API_KEY` をプロキシサーバーに設定して起動し、クライアント側の接続先をプロキシに向けます。

### 1. プロキシサーバー側の設定

`.env` ファイルに、あなたの本物の Anthropic API キーを記述します：

```env
PORT=4040
ANTHROPIC_API_KEY=sk-ant-api03-... # あなたのキー
```

この状態で `npm start` を実行すると、**「本物 API 中継モード」** で起動します（プロキシ自身はAPIキーを保存・漏洩せず、ヘッダーに透過処理して Anthropic に安全に中継します）。

### 2. クライアント側の接続設定

ターミナルで `ANTHROPIC_BASE_URL` にプロキシのURLを指定し、Claude Code を起動します。

```bash
# 接続先を yakushield プロキシに向ける
export ANTHROPIC_BASE_URL=http://localhost:4040/v1

# Claude Code を起動
claude
```

これで、Claude Code が実行するすべての操作や自律タスクのトークン数が yakushield に集計され、ダッシュボードにリアルタイム表示されます。また、ダッシュボードのスライダーで設定した予算上限（例: $3.00）を超えた場合、プロキシが物理的にリクエストを遮断し、Claude Code をその場で安全に停止させます。

## 🧪 デモ・シミュレータでのテスト方法

1. `npm start` で起動後、ブラウザで `http://localhost:4040` にアクセスします。
2. 画面右側の **「デモ用リクエスト・シミュレータ」** に移動します。
3. 日本語プロンプトを書き、**「擬似リクエストを送信」** をクリックします。
4. 今日のLLMコストと、**「日本語トークン浪費メーター」** がリアルタイムに上昇することを確認します。
5. スライダーを現在の消費額より低く（例: $1.00）設定します。
6. 再度「擬似リクエストを送信」をクリックすると、**予算ブレーカー警告バナーが赤く点滅し、通信が遮断され、トースト警告が表示される様子** を体験できます。

## 🔒 セキュリティとプライバシー

* `yakushield` はローカル環境（`localhost`）だけで稼働します。外部サーバーへのログ送信やAPIキーの送信は一切行いません。
* `ANTHROPIC_API_KEY` はお使いのローカルマシンのメモリ内、またはお客様のクライアントから直接送信されたものを中継するだけであり、ディスク等に保存することはありません。
