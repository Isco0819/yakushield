🔌 Claude Code 差し込み手順

Claude Code に yakushield を差し込むには、環境変数 ANTHROPIC_BASE_URL を設定した状態で claude を起動します。

  1. プロキシサーバーを起動しておきます。
  2. 次のコマンドで Claude Code を起動します： 
    export ANTHROPIC_BASE_URL=http://localhost:4040/v1
claude
